Free Pre-Deploy GitHub Action Integration

Automatically review prompt diffs in Pull Requests and enforce carbon budget policies.

.github/workflows/promptgreen_gate.yml Zero Cost GitHub Action 
name: PromptGreen Carbon Gate Review
on: [pull_request]
jobs:
  carbon_gate_review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with: { python-version: '3.11' }
      - run: pip install promptgreen
      - run: python -m promptgreen.cli git-diff --commit HEAD~1 --budget 0.5 --mode warn
